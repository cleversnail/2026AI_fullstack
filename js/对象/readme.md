# 构造函数
 - 被 new 调用的函数
 - 用于批量创建对象实例

 1. js官方提供了 Object、Array 等构造函数，用于创建对象实例。

 ## prototype 原型 （显示原型）
  - prototype 是每一个函数天生就拥有的属性，且它是一个对象

 ## __proto__ 对象原型（隐式原型）
  - __proto__ 是对象天生拥有的属性，且它是一个对象

 ### 实例对象的隐式原型等于构造函数的显示原型
  - V8 引擎在访问对象中的属性时，会先查找对象本身显示拥有的属性，如果找不到，就会去对象的隐式原型上查找


# 包装类
 - 原始类型不能添加属性和添加方法
 
  1. 当用户创建一个x字面量时，v8会默认执行 new Xxx()， 得到一个对象实例
  2. 因为原始类型不能添加属性和添加方法，所以，v8在new出这个实例对象后，会立即做一个拆箱操作
  3. 所以给原始类型添加属性和方法，最后访问得到的其实是实例对象上不存在的属性和方法，也就是undefined
